## PART II · SYNTHESIS — THE COMMON SYSTEM (what makes these refs ONE family)

### S1 · The depth ladder (the shadows the owner cannot see in our build)

Every reference structures space as **registered elevation tiers** — never flat:

| tier | what lives there | light theme | dark theme (R7) |
|---|---|---|---|
| L0 | canvas | #F1F1F3–#F2F2F4 flat field | near-black (~#0A0A0B) with faint warm cast |
| L1 | app panel / sidebar | WHITE card, shadow y8 blur24+ ~10%, hairline edge | **one lightness step up** (~#131316), rounded, soft shadow, visible edge |
| L2 | cards / trays | white, whisper shadow; hover lifts −2px + bloom | one–two steps up (~#17171A), **visible drop shadow** y6–10 blur16–24 |
| L3 | elevated controls | **black pill** (#17171A) + strongest shadow (y4–6, blur14–18, 28–35%) | **white pill** (ink inversion) + shadow |
| L4 | overlays / glass | glass over receded content, biggest shadow | frosted dark glass over dimmed content |

Rules extracted: shadows are **y-only, never x**; blur ≈ 2–3× the y-offset; opacity 8–18% light / 25–45% dark; **in dark themes depth = surface steps + edge highlights FIRST, shadow second** (black-on-black shadows are invisible — the refs get depth from the STEP, then confirm it with shadow).

### S2 · Ink inversion (the loudest element flips)

The highest-emphasis control is always the inverse pill: black-on-light in R2/R12 (Read, active chips), white-on-dark in R7/R11 (Read, active chip). Selection tints stay same-family (grey step up/down). Never both loud at once.

### S3 · Glass is a ladder over CONTENT

R10's three levels (clear / blur / frosted) + R3/R9: glass only reads when rich content sits behind it (receded text, imagery, glow stations). Hairline light border on every glass surface. Blur ≈ 12–40 by tier.

### S4 · Selection language

Soft rounded-rect tint fill, R ≈ 10–14, full cell or full row — **never underline, never left-bar**. On tinted panels the fill can invert (R6: white pill on grey rail, black pill for section rows).

### S5 · Type voice

One sans family; **chrome = regular 400, never bold**; display/headers = **medium 500-class confidence** (R7's greeting — NOT thin/light); hierarchy via size + grey steps (100% → 60% → 40%), never via weight jumps; tracking −0.01/−0.02em on display; caps-letterspaced eyebrows at ~11px.

### S6 · Icon language

Fine-line 1.5–2px stroke, 20px grid (16/20/24 ladder per R14), grey default → ink on selection; ONE accent allowed corpus-wide: a notification dot (R6 pink, R8 blue tint).

### S7 · The motion vocabulary (what the refs imply)

1. **Hover = lift + shadow bloom**: translateY(−2px) with shadow tier jump + border brighten, 150–200ms — objects respond like objects.
2. **Press = scale .97–.98**, 80–120ms, shadow tightens.
3. **Expansion = width spring + label stagger** (labels follow the panel by ~60–80ms).
4. **Overlay = two-layer choreography**: content recedes (dim + slight blur + scale) while the tool floats in — R3/R5.
5. **Progress fills animate** on view (R8/R7).
6. **Entrance = rise + fade** ~20px, staggered ~40ms (R9/R13).
7. **Tooltips** fade + rise ~8px with anchored pointer (R5's tail).
8. All of it transform/opacity only — sub-16ms (INT-009.D).

### S8 · Palette

Grayscale only. Dark = **warm-neutral night, never blue**. Light = paper. Ink inversions are the only "color events". (R13's holographic art and R15's warmth are content, not chrome.)

### S9 · The vibe equation

**(floating panels on a quiet canvas) + (objects with soft physical shadows) + (ink-inverted controls) + (glass over receded content) + (confident medium type) + (generous negative space) = quiet premium tactility.**
Words the whole corpus shares: floating · soft · tactile · hushed · confident · warm-neutral · precise.
